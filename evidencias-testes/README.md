# Capturas completas dos testes funcionais — SGE ISDB

Este arquivo conserva as 33 capturas originais que integravam o Apêndice F da Monografia FINAL 2026, versão 8.
As imagens foram extraídas directamente do ficheiro DOCX, sem reconstrução, manipulação visual ou alteração dos conteúdos.
O ficheiro Word reorganizado conserva 14 capturas representativas e remete para este arquivo complementar.

## Consulta do arquivo

Este arquivo está publicado no repositório público [SGSDB-evidencias](https://github.com/EduardoJr10/SGSDB-evidencias), na pasta `evidencias-testes/`.

## Utilização como evidência

As capturas são evidências visuais dos cenários de teste descritos na secção 5.5 da monografia. A interpretação do teste depende também do procedimento, resultado esperado e resultado observado documentados no Quadro 4.
Uma imagem isolada não comprova, por si só, todos os aspectos de uma regra de negócio nem a cobertura integral do sistema.

## Reprodutibilidade e integridade

O ficheiro `manifesto.csv` identifica título, nome original, dimensões, presença na monografia condensada e hash SHA-256 de cada imagem.
